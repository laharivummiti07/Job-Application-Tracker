# Job Application Tracker

A responsive React-based Job Application Tracker that helps users manage job applications and track their application status.

## Features

- Add job applications
- Edit existing applications
- Delete applications
- Search by company, role, or location
- Filter by application status
- Sort applications
- Form validation
- LocalStorage persistence
- Dark mode
- Responsive design
- Dashboard statistics
- Empty-state handling

## Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- Browser LocalStorage
- Vite

## Run Locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Main Concepts Used

- React functional components
- useState
- useEffect
- useMemo
- Controlled forms
- Conditional rendering
- Array map/filter/sort
- LocalStorage
- Responsive CSS
